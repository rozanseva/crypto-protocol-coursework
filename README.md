
# Курсовая работа: Разработка криптографического протокола DSA

## Цель работы: изучение способа построения и разработка криптографического протокола.

## Структура репозитория

- main.py - Визуализация схемы DSA.
- E.py - Аутентификация Фейге-Фиата-Шамира.
- prime.py - Генерация простых чисел.
- prandom.py - Генератор псевдослучайных данных.
## Библиотеки
Весь функционал реализован вручную через базовую арифметику и встроенные возможности языка. (по условию задания)
random: генерация псевдослучайных чисел для ключей.
time: получение системного времени для начальной энтропии.
threading: параллельные вычисления.
math: вспомогательные математические операции.
